# 🖼️ 图片压缩GUI工具

一个功能强大的图片压缩工具，提供直观的图形界面，支持智能目标大小压缩、安全预览机制和批量处理。

## ✨ 主要特性

### 🎯 智能压缩算法
- **按目标大小压缩**：设定目标文件大小（如500KB），程序自动二分查找最优质量参数
- **按质量参数压缩**：手动设置JPG/PNG压缩质量（10-100）
- **透明通道保留**：支持PNG透明效果保留（默认启用）
- **误差控制**：目标大小模式下，压缩结果误差控制在50KB以内

### 🔍 安全预览机制
- 压缩结果先保存到 `temp_preview` 临时目录
- 并排对比显示原图和压缩后图片
- 显示详细信息：文件大小、尺寸、压缩率
- 确认满意后才覆盖原图，操作更安全

### 📦 批量处理能力
- 支持递归扫描目录下所有图片
- 可设置文件大小阈值筛选（只压缩大于指定大小的文件）
- 多线程并发处理（可调节线程数，默认20）
- 实时进度显示和统计信息
- 压缩完成后可选择性应用

### 📋 预设方案
内置4种常用压缩场景：
- **微信分享**：500KB以内，质量80，适合微信、QQ等社交平台
- **网页优化**：200KB以内，质量75，适合网站图片优化
- **文档用图**：1MB以内，质量85，适合文档、PPT插图
- **高质量保存**：按质量92保存，保持高画质

### 🎨 支持格式
- **JPG / JPEG**：有损压缩，适合照片
- **PNG**：无损或有损压缩，支持透明通道

## 📥 安装与使用

### 前置要求
- Python 3.7 或更高版本
- Pillow 图像处理库

### 安装步骤

1. **安装Python依赖**
   ```bash
   pip install Pillow
   ```

2. **启动程序**
   - **Windows用户**：双击 `compress-gui.bat` 
   - **命令行启动**：
     ```bash
     python scripts/compress-images-gui.py
     ```

## 📖 使用指南

### 单图测试模式

1. **选择图片**
   - 点击"选择图片文件"按钮
   - 选择要压缩的JPG或PNG图片

2. **设置压缩参数**
   - **压缩模式**：
     - 按目标大小：设定目标KB数，程序自动优化
     - 按质量参数：手动调整JPG/PNG质量滑块
   - **目标大小**：输入或点击快捷按钮（500KB/1MB/2MB）
   - **透明通道**：勾选以保留PNG透明效果（默认启用）

3. **开始压缩**
   - 点击"🚀 开始压缩"按钮
   - 等待处理完成

4. **预览对比**
   - 左侧显示原图，右侧显示压缩后效果
   - 查看文件大小、尺寸、节省百分比等信息
   - 可点击"📁 打开临时目录"查看临时文件

5. **应用或取消**
   - 满意后点击"✓ 应用到原图"覆盖原文件
   - 不满意点击"✗ 取消"，可调整参数重新压缩

### 批量压缩模式

1. **选择目录**
   - 点击"选择图片目录"按钮
   - 选择包含图片的文件夹（会递归扫描子目录）

2. **设置筛选条件**
   - **最小大小**：设置文件大小阈值（MB），只压缩大于此值的图片
   - **并发线程**：设置同时处理的文件数（1-50），默认20

3. **设置压缩参数**
   - 同单图模式，设置压缩模式、目标大小或质量参数

4. **开始批量压缩**
   - 点击"🚀 开始批量压缩"
   - 查看扫描结果，确认文件列表
   - 确认后开始批量处理

5. **查看进度**
   - 实时进度条显示处理状态
   - 文件列表显示每个文件的处理结果
   - 统计信息：总文件数、已处理数、节省空间等

6. **应用结果**
   - 压缩完成后，选择是否应用到原文件
   - 确认后批量覆盖原图

### 使用预设方案

点击预设按钮可快速应用常用配置：
- **微信分享**：适合微信等社交平台（500KB）
- **网页优化**：适合网站优化（200KB）
- **文档用图**：适合文档插图（1MB）
- **高质量保存**：保持高画质（质量92）

## ⚙️ 高级功能

### 透明通道处理

**启用透明通道保留时**（默认）：
- PNG图片：保留原有透明通道
- JPG图片：不支持透明，自动使用白色背景填充

**禁用透明通道保留时**：
- PNG图片：转换为RGB模式，使用白色背景，可能转为JPG格式（文件更小）
- JPG图片：保持不变

### 智能压缩算法原理

当选择"按目标大小"模式时：
1. 使用二分查找算法，范围：质量10-95
2. 每次测试压缩结果，与目标大小比较
3. 最多迭代10次，找到最优质量参数
4. 误差容忍度：50KB
5. 在保证文件大小的前提下，尽可能保持高画质

### 临时文件管理

- 临时文件保存在 `temp_preview/` 目录
- 命名格式：`preview_原文件名.jpg/png`
- 可通过"清理临时文件"菜单清空
- 退出程序时自动清理

## 📊 性能与限制

### 性能指标
- 单图压缩：通常2-5秒（取决于图片大小和目标参数）
- 批量压缩：20线程并发，每秒可处理5-10张图片
- 内存占用：50-200MB（取决于图片大小）

### 已知限制
- 仅支持JPG和PNG格式
- 不支持GIF动图、WEBP等格式
- 不支持图片尺寸调整（保持原尺寸）
- 批量模式下，文件名冲突可能导致覆盖

## 🛠️ 技术实现

- **GUI框架**：Tkinter（Python内置）
- **图像处理**：Pillow (PIL Fork)
- **并发处理**：ThreadPoolExecutor（Python内置）
- **算法**：二分查找 + 图像质量优化

## 🐛 常见问题

### Q1: 启动失败，提示找不到Pillow
**解决方法**：
```bash
pip install Pillow
```

### Q2: 压缩后图片质量下降明显
**解决方法**：
- 提高质量参数（85-95）
- 或使用"高质量保存"预设
- 目标大小不要设置过小

### Q3: 批量压缩后部分文件失败
**可能原因**：
- 文件损坏或格式不支持
- 文件被占用（其他程序打开）
- 磁盘空间不足

### Q4: 透明PNG变成白色背景
**原因**：
- 未勾选"保留透明通道"选项
- 或保存为JPG格式（JPG不支持透明）

### Q5: 如何恢复压缩前的原图？
**解决方法**：
- 压缩前建议备份重要图片
- 或在应用前先在临时目录查看效果
- 程序不提供自动备份功能
